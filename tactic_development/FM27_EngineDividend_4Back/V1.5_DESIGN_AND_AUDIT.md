## D5 诊断与设计假设

V1.4 英超 38 场：27胜2平9负、101:53、83分；xG 92.62、xGA 43.46、绝佳机会 100/39。相较 V1.3，进攻指标显著上升，但 xGA +9.19、对手绝佳机会 +12、失球 +23、积分 -5。主场 17胜0平2负，客场 10胜2平7负；客场 xGA 23.28、对手绝佳机会 22。攻击端应保留候选，防守风险应成为下一轮优先项。

V1.5 做两项全局调整：
1. 心态 `4 → 3`（平衡/中性档 → 谨慎档）。
2. 球队 TI 防线高度 `DEFAULT → LOWER`（较低）。

保留高位防守介入线（`LineOfEngagement=HIGH_PRESS`，native bit 61）与团队较多逼抢（`TriggerPress=MORE_OFTEN`，native bit 66），测试“较低防线 + 高位压迫”而不是极端压迫。比赛节奏较高、进攻宽度较宽保留。AML 内锋（进攻）+ 内切 + 自由跑位保留，以保护 V1.4 的进攻产量假设。

这不是单项因果试验：心态与防线高度同时改变。它是针对 V1.4 组合级防守问题的综合风险控制迭代。若 V1.5 防守改善而进攻明显回落，后续需拆分两项调整进行对照。

## 四类决策

### 继承保留
- IP 四后场 DL/DCL/DCR/DR（强制结构）。
- 22 阶段位置/角色/职责/PI 全部暂时继承；标签为结构性暂留、单项未准入。
- AML 内锋/进攻、内切、自由跑位组合暂留，因 V1.4 进攻指标正向；仍是组合关联，非因果准入。
- 较高比赛节奏、较宽进攻宽度、高位介入线、较多团队逼抢与其余 TI bits 暂留；单项效果未准入。
- 空 style string、FourCC 与 opaque 原生载体按格式继承。

### 替换淘汰
- 心态 `4 → 3`。
- 防线高度 `DEFAULT → LOWER`。
- 旧配置退出 V1.5，不代表在其他阵型/情境中无效。

### 新增待验证
- 心态 3 + 较低防线 + 高位介入线 + 较多团队逼抢的协同结构。
- 重点验证客场 xGA、对手绝佳机会、客场失球、积分；进攻端以 xG、我方绝佳机会和进球为保护指标。
- 风险：谨慎心态压低前场积极性；低防线让对手增加外围/禁区前沿控球。

### 证据不足
- V1.4 角色/PI 无法按逐场战术槽位完整解码；不可断言 AML 角色造成防守恶化。
- 593/973 球员报告行缺少 role_code；63 次出场身份未识别；3 球未归属。
- build 27.1.1+2511875 未上游登记；借用 schema-6 布局，仅本次本地对账通过。
- V1.4 与 V1.3 不是同存档、同 seed 的受控对照。
