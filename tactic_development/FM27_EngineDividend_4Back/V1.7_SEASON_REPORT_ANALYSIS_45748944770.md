## 10. 数据结论与后续版本目标

- V1.7 的防守改动取得了正向机会控制观察：xGA下降、对手绝佳机会下降，尤其客场指标改善；这组 DML 屏障 + DMR 较少主动离位的组合应继续保留。

- 下一版目标：保持 IP 四后场、V1.7 全部 IP 角色/PI、心态4与共享TI；仅重构 OOP 结构/角色和必要 PI，测试 OOP strikerless 5-2-3 是否进一步降低客场 xGA/绝佳机会，同时不损害我方 xG/绝佳机会。
- 评估门槛：D5至少完成38场英超；报告仍需逐项标记 parser/build 兼容性、覆盖率和未归属进球。D3不等于D4导入或D5实战有效。
