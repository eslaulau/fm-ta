## 9. R4 设计决策

### 继承保留

- IP 四后场位置 DL/DCL/DCR/DR；4-2-3-1 前场四人位置结构。原因：四个进攻位置贡献约 52.0 xG，未见拆除 AMC/单前锋的充分证据。
- TargetForward Attack、InsideForward Attack、FreeRole Attack、Winger Support；保留支点、内侧终结、自由人和右侧供给通道。
- OOP 5-2-3 无锋五后卫、双后腰保护、IP DL/DR 与 OOP HoldingFullBack 的阶段转换。
- 高位逼抢遭遇线 + 极低防线 + Drop Off More；后场三中卫/五后卫角色不额外叠加更多逼抢。
- OOP 外场球员 Tackle Harder；在原生权限允许的位置使用 Trigger Press More Often，DCL 保持 Less Often。

### 替换淘汰

- DR：WingBack Support → WingBack Attack；IP 仍为 DR 槽位，OOP 仍转换为 HoldingFullBack。目的：提高右侧有球前插和边路供给。
- DMR：DefensiveMidfielder Defend → BoxToBoxMidfielder Support；OOP 仍转换为 WideCoverDefensiveMidfielder Defend。目的：IP 增加第二线跑动，OOP 通过宽幅补位后腰重新锁住防守责任。
- AMC FreeRole 的 Shoot Less Often PI 移除；保留 FreeRole 与团队减少远射，避免显式 PI 额外压低中路终结。
- AML/AMR 的 OOP TrackingWinger 改为 InsideOutletWinger / WideOutletWinger；ST→AMC 的 OOP AttackingMidfielder 改为 CentralOutletAttackingMidfielder。目的：无球阶段仍是无锋 5-2-3，但三个前场槽位作为内侧、外侧和中路接应出口，不再全部回撤成跟防型边锋。
- 团队 Pass Into Space → Pass To Feet；PATIENCE Hit Early Crosses → Work Ball Into Box。保留 High Crosses、Back Post、Byline、较高节奏和直接推进，测试“先进入更好区域、再传后点”与减少越位的组合。

### 新增待验证

- IP BoxToBoxMidfielder Support ↔ OOP WideCoverDefensiveMidfielder Defend 的跨阶段错位。
- IP WingBack Attack ↔ OOP HoldingFullBack Defend 的右侧进攻/防守职责错位。
- OOP 三个 outlet roles 的无锋高位出口组合。
- Pass To Feet + Work Ball Into Box + High Crosses + Back Post 的传球/传中时机组合。
- 保留 OOP Tackle Harder 广泛覆盖；前场三人及双后腰在原生权限允许范围内 Trigger Press More Often。

### 证据不足

- Exporter 没有每场 IP/OOP 角色、PI/TI 执行、传中落点、禁区触球、xA、射门位置或具体进攻回合事件；本轮配置变化只能归因到组合假设。
- 角色默认行为 GameID 的完整自然语言说明仍未解码；不能把角色名当作全部行为说明。
- Build 27.1.1+2511875 使用借用的 schema-6 解析布局，虽本地交叉核对通过，仍需持续观察新 build 兼容性。
