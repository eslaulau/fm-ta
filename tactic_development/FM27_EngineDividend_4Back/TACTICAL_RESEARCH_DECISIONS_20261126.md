# FM27 四后卫战术研究：配置取舍与下一轮结构决策（2026-11-26）

> **历史研究快照（2026-11-26）：** 本文数据与结论保留作历史证据，不再定义当前阵型/位置搜索范围。2026-11-27新规则生效后，IP仅允许4-2-3-1/4-3-3/4-1-2-3，OOP位置图和心态4固定，红框15项TI固定；只可调整角色/职责、PI和非红框TI。

## 本轮结论先行

本轮重新逐项读取 V0.9–V1.8 与 2.2 的原始配方 JSON，并核对对应的 38 场英超赛季报告。研究结论不是“哪个阵型名字更好”，而是以下五个明确取舍：

1. **V1.3 是目前本地历史中最值得作为攻守骨架参照的四后卫版本**：88分、83:30、xG 80.54、xGA 34.27。它的进攻并不弱，防守机会控制明显优于2.2。
2. **V1.4 的 AML 内锋（进攻）是强进攻增益候选，但不能单独作为升级**：进球、xG和绝佳机会大幅增加，防守机会与积分却恶化。
3. **2.2 的双中锋+双肋部中场+攻击型前腰没有把赛季 xG 总量拉开**：比 V1.3 多1.29 xG，但少4分、失球多10个。它的机会更集中在高质量档（绝佳机会98 vs 65），但射门量更少、xGA更高。
4. **V1.8 证明“无球改成五后卫”不能只看进攻上升**：与 V1.7 相比，xG +14.58、绝佳机会 +24，但 xGA +15.54、对手绝佳机会 +20、积分 -10。V1.8 的整套 OOP 结构暂不作为主线。
5. **下一轮不再做“低平传中改曲线传中”这种单点小修作为升级。** 应测试完整结构融合：保留2.2有球四后卫菱形双前锋攻击骨架，替换为V1.3已验证过的无球防守分工；同时把进攻端的两翼宽度与中路占位重新分配。

> 所有历史版本来自不同存档/赛季，属于描述性对照，不是同 seed A/B。以下结论按“可保留候选/风险信号/待验证”区分，不把相关性写成因果。

## 2. 2.2 对 V1.3：攻击人数增加，却没有明显增加总 xG

### 有球结构差异

| 位置 | V1.3 | 2.2 | 判断 |
|---|---|---|---|
| DL | 内收边后卫 / 防守 | 翼卫 / 支援，拉开宽度、后点 | 2.2左路更高更宽；失去内收后场连接点 |
| DCL | 中后卫 / 防守 | 出球中卫 / 防守 | 2.2双侧都偏出球 |
| DCR | 出球中卫 / 防守 | 出球中卫 / 防守 | 基本保留 |
| DR | 翼卫 / 进攻 | 翼卫 / 支援，拉开宽度、后点 | 2.2右路进攻职责降低 |
| DMC | 无单独DMC | 防守中场 / 防守，保持位置、少冒险 | 2.2增加单后腰屏障 |
| MCL/MCR | 中前卫支援 + 肋部中场进攻 | 双肋部中场进攻 | 2.2双侧都向前冲，少一个稳定接应/留位中场 |
| AML/AMR | 双组织型边锋 / 支援 | 无边锋位 | 2.2撤掉两侧边锋，边路宽度主要交给翼卫 |
| AMC | 前场组织核心 / 进攻 | 攻击型中场 / 进攻 | 2.2前腰更偏攻击终结 |
| ST | 抢点前锋 / 进攻 | 双中锋 / 进攻 | 2.2增加第二个禁区攻击点 |

### 结果差异

- 2.2 比 V1.3 多进4球，但少4分；多失10球。
- xG 只多1.29（81.83 vs 80.54），说明攻击人数增加没有带来同等幅度的整体机会产量提升。
- 2.2 的射门少59次（492 vs 551），但绝佳机会多33次（98 vs 65）。这更像是机会结构发生变化：总射门量下降、较高质量机会占比上升，而不是进攻全面增强。
- 2.2 xGA 比 V1.3 高9.31（43.58 vs 34.27），对手绝佳机会多12次。失球多10个与机会控制变差方向一致。
- 2.2 的传中1,358次/210次成功，约15.5%；V1.3为1,288次/192次成功，约14.9%。2.2传中完成率略高，不能把低平传中认定为本赛季失败主因。

### 真正值得研究的结构问题

**2.2的中路攻击点过多、稳定接应点不足，是一个值得优先检查的配置问题。** 双肋部中场进攻 + 攻击型前腰 + 双中锋，形成五个中路/肋部攻击职责；两侧边路没有 AML/AMR 常驻接应，宽度主要依赖两名支援翼卫。该配置可以解释为什么绝佳机会数高，但整体射门和xG没有明显超过V1.3；目前是结构假设，尚无热区/接球点数据证明。

可执行的战术取舍：
- 不要把双肋部中场进攻、攻击型前腰、双中锋四类攻击职责全部同时最大化。
- 保留双中锋作为禁区双点候选，但至少让一名中场承担稳定接应/控位，而不是两名肋部中场都攻击。
- 让一侧边路有明确的持球/接应点，另一侧翼卫提供宽度；不要要求两侧翼卫都承担同样的后点传中任务。
- 2.2 的直接传球、极高节奏和向前传球组合已经产生2.15场均xG，不应为了提高控球率而整体改成慢速控球。

## 3. AML 内锋进攻：有效增产，但需支付防守代价

V1.3→V1.4 的主要配方变化是 AML 从“组织型边锋/支援”改成“内锋/进攻”，并加入内切与自由跑位；其他共享TI和OOP骨架保持不变。

| 指标 | V1.3 | V1.4 | 差值 |
|---|---:|---:|---:|
| 进球 | 83 | 101 | +18 |
| xG | 80.54 | 92.62 | +12.08 |
| 我方绝佳机会 | 65 | 100 | +35 |
| 失球 | 30 | 53 | +23 |
| xGA | 34.27 | 43.46 | +9.19 |
| 对手绝佳机会 | 27 | 39 | +12 |
| 积分 | 88 | 83 | -5 |

这不是“内锋不好”，而是**内锋进攻职责的攻击增益没有转化成更多积分，因为同一版本的防守结果恶化得更大**。因此：
- 内锋进攻 + 内切 + 自由跑位：保留为单侧攻击武器。
- 不要两侧同时复制成双内锋攻击，除非另一侧的边后卫/后腰能覆盖其身后空间。
- 当前最合理的后续试法是只让一侧成为内锋攻击，另一侧保留组织型边锋/支援或其他稳定宽度角色；不要同时把两侧翼卫、双肋部中场、AMC都设为高攻击职责。

## 4. 中场职责：V1.6 与 V1.7 的防守信号

V1.6→V1.7 的 IP 基本相同，变化集中在 OOP 双后腰：
- V1.6：一侧边路补位后腰更常触发逼抢，另一侧逼抢后腰。
- V1.7：边路补位后腰改为较少触发逼抢；另一侧改为屏障后腰。
- 结果：对手绝佳机会40→30，xGA46.33→44.13，实际失球37→36；但我方进球87→79，积分89→82。

解释：
- “双后腰都积极上抢”没有证据证明能提高整体防守质量。
- “一名屏障后腰 + 一名边路补位后腰且减少盲目上抢”是更值得保留的防守组合。
- V1.7的防守机会控制指标改善，但积分下降主要伴随我方进球减少；不能把其简单称为全面升级。
- 对本项目，优先采用分工而不是两名后腰同时压迫：一名守中路/保护肋部，一名负责边路补位；后者触发逼抢不要默认设为更多。

## 5. OOP 五后卫：区分结构，不要一概而论

V1.8与V1.7的IP和共享TI基本完全相同，主要差异在OOP结构。V1.8把边后卫改成逼抢翼卫、两名中卫改成补位边中卫，并把一名中场回撤成第三中卫，前场保留边锋出口。结果是进攻机会和防守机会同时增加：
- xG +14.58、我方绝佳机会 +24；
- xGA +15.54、对手绝佳机会 +20；
- 进球 +19、失球 +19；
- 积分 -10。

因此不能只说“5-2-3不行”。2.2同样有球四后卫、无球形成五后卫，但它的无球五人线是两名边后卫+三名中卫，双后腰保护，前场三人；并未采用V1.8的双补位边中卫+双逼抢翼卫组合。两者的防守结果不同。下一轮要比较的是**五人后线由什么角色构成、边路谁上抢、后腰谁补位**，而不是只比较“5-2-3”阵型名称。

## 6. 球队指令：哪些先保留，哪些不再盲目加码

### 先保留为主线候选
- 比赛节奏：较高/极高。2.2在低控球下仍有2.15场均xG，V1.3也以较高节奏取得88分。
- 向前传球：保留直接推进思路，但不要把更多直接传球与所有球员更多冒险同时叠加。
- 向空当传球：当前数据没有证明它造成越位浪费，不关闭。
- 进攻宽度：较宽可保留；2.2两翼翼卫承担宽度，中央攻击职责密集，不能再把宽度继续收窄。
- 远门柱传中：作为单侧翼卫的候选，不应默认两边都用同一传中目标。

### 暂不作为主线默认
- 低平传中：2.2全季成功率约15.5%，未胜场成功率12.9%，胜场16.7%；有差异但没有因果证据。可列入后续单变量实验，但不应先验判死刑。
- 两侧翼卫都“支援+拉开宽度+后点”：没有足够证据证明这是最佳双侧组合。下一版应尝试一侧承担高位/进攻，一侧更稳的非对称分工。
- 团队“更多触发逼抢”不应机械套到每个中卫/后腰。历史配置中，中央中卫较少触发逼抢、前场和边路负责主动压迫的分层结构更有依据。

### 需要谨慎的组合
- 高位压迫线 + 较低防线：可以测试，但不要同时最大化全队压迫强度。
- 反抢 + 极高节奏 + 直接推进：是进攻转换候选，不应因为控球率低而删除；同时观察失去球权后对手第一次推进能否直接打到中卫身前。

## 8. 下一轮战术配置建议（明确到位置）

这是一份从历史证据得出的**下一轮研究配方方向**，不是已通过游戏D4/D5的战术：

### 有球：保留四后卫，减少中路职责重叠

| 位置 | 建议角色/职责 | 具体目的 |
|---|---|---|
| DL | 内收边后卫 / 防守（优先基准） | 提供后场中路接应，不与左侧内锋同时冲入同一肋部 |
| DCL | 中后卫 / 防守 | 保持普通四后卫中卫槽位，不用边中卫角色 |
| DCR | 出球中卫 / 防守 | 作为一侧向前输送点，另一侧保持稳健 |
| DR | 翼卫 / 进攻或支援（先选其一测试） | 提供唯一明确的高位外线宽度，不要求两侧同样前插 |
| DMC | 防守中场 / 防守，保持位置、少冒险 | 保护两名中卫身前，防止双肋部中场同时前插后无人接管中路 |
| MCL | 肋部中场 / 进攻 | 保留一个纵深攻击点 |
| MCR | 中前卫 / 支援，更多前插（不再与MCL同为肋部进攻） | 提供第二线接应与后插上，但减少同线拥挤 |
| AML | 内锋 / 进攻，内切；自由跑位作为可测选项 | 采用V1.4显示出的攻击增产方向，但只用一侧 |
| AMR | 组织型边锋 / 支援 | 保留边路接应与传球出口，避免两侧同时内收 |
| AMC | 前场组织核心 / 支援或攻击（先支援） | 连接中场与前锋，避免与双肋部攻击职责争同一禁区通道 |
| STL/STR | 双中锋中一攻一支援；优先测试抢点前锋/进攻 + 拖后前锋/支援 | 保留双前锋牵制与禁区人数，同时制造一名回撤接应者 |

### 无球：以V1.3的保护框架为基准，按2.2的三线压迫原则分工

- DR：留守边后卫 / 防守。
- DCR：中后卫 / 防守，较少触发逼抢。
- DCL：补位中卫 / 防守，较少触发逼抢。
- DL：逼抢边后卫 / 支援，更多触发逼抢。
- DMR：边路补位后腰 / 防守，较少触发逼抢。
- DML：屏障后腰 / 防守。
- MR/ML：回防边前卫 / 防守，承担边路第一压迫。
- MC：屏障中场 / 防守。
- AMC：分球型前场支点 / 进攻，负责前场出口；前场边路压迫由回防边前卫和边锋职责分担。

### 本轮不建议继续沿用的做法
- 两名肋部中场都进攻 + 攻击型前腰 + 两名中锋都进攻，全部叠在同一中路。
- 两侧翼卫同为支援并都指定后点，边路角色缺乏非对称分工。
- 两名后腰都主动上抢，尤其在边后卫已经高位压迫时。
- 无球阶段同时使用双逼抢翼卫+双补位边中卫，却没有足够的后腰/边路保护。

## 9. 下一轮验证指标

不要只看积分。必须同时记录：
1. 积分、胜平负、进球/失球。
2. xG、xGA、我方/对手绝佳机会。
3. 射门数、xG/射门、射正率。
4. 传中尝试/成功率，并分胜/平/负。
5. 主客场xG/xGA与对手绝佳机会。
6. 对手反击后的第一次推进、边后卫身后接球、禁区横传/倒三角机会（若Exporter可得则导出；不可得则明确缺失）。
7. 38场D5后再判断是否接近109分；不把单场大胜或短期测试称作升级。

**当前最值得执行的完整实验：** 以2.2的IP四后卫菱形双前锋为起点，按上表将中场攻击职责改成一攻一支援，并将OOP换成V1.3的分层四后卫保护框架；单侧AML内锋攻击、另一侧组织型边锋支援。该方案一次测试结构组合，不声称能单独识别每条指令因果。所有新版本仍从V0.5原始基线重建。
