## 1. PPG 2.85 目标判断

- 项目最高目标：**PPG ≥ 2.85**。
- 历史对照：V1.6 记录 89 分（PPG 2.342），V1.3 记录 88 分（PPG 2.316），V1.8 记录 72 分（PPG 1.895）；均未达到目标。
- 本轮主要问题：历史版本与目标仍有明显积分差距；需要同时提升进攻产量和防守机会控制，不能只压低 xGA 或只堆进攻人数。
- 本轮要改善的 PPG 相关机制：以较高节奏和较宽进攻空间提高有效进攻回合与边路供给；以极低防线保护身后，以高位遭遇线干扰对手后场出球；用双后腰屏障与中卫低触发频率降低第一线被绕过后中卫被拉出位置的风险。
- PPG 提高路径：争取把高位压迫带来的仓促出球转化为更多前场夺回和更短进攻路径，同时限制对手身后球和禁区核心区域的高质量机会；通过提高胜场、减少高质量失球导致的败场来提高积分。该路径是待验证设计假设，不是性能承诺。

## 2. 历史证据与本轮问题

- 正向证据：V0.5 原始 TI 已同时包含高位遭遇线与极低防线，说明该错位组合是原生可构建配置；V1.6 是历史积分较高版本（89分），其较高节奏、较宽进攻宽度和较高逼抢频率可作为进攻侧参考。
- 负向证据：V1.8 的历史赛季积分明显低于 V1.6/V1.3；不能因其 OOP 无锋/三前场结构曾被视为 META 就直接继承。V1.6/V1.3 也未达到 2.85 目标。
- 本轮问题定级：结构/协同级与指令级共同处理。防守端避免中卫被第一线压迫任务牵引；进攻端避免极窄宽度导致外侧空间与边路出口不足。
- 数据不足：没有本轮 2.0 比赛事件数据，无法确认压迫触发是否与防线纵深完全独立，也无法直接量化中场过渡区的风险；不得把机制推断写成引擎事实。
- 外部 META/机制依据：项目既有引擎红利资料库和历史 V0.5/V1.x 原生配置。当前设计重点不是复制排名战术，而是构造可验证的分层压迫错位。

## 3. 四类配置决策

### 继承保留
- V0.5 的有球四后场槽位 DL/DCL/DCR/DR，原始 native identity 作为重生基准保留。
- 保留高位遭遇线与极低防线的组合；保留丢球后重新组织防守、积极铲抢、门将短传与前场传入空当等已存在的团队设置。证据等级：原生配置存在已确认；比赛收益仍待验证。

### 替换淘汰
- 团队逼抢频率：极多 → 更多。避免团队强度直接取最大值，把压迫任务更多交给指定位置的个人触发频率。
- 有球宽度：极窄 → 较宽；比赛节奏：极高 → 较高。历史 V1.6 的较宽与较高节奏是参考，不宣称单项因果。
- 有球左后卫：边后卫策应 → 内收型边后卫防守；有球右后卫：翼卫策应 → 翼卫进攻。制造左右侧行为错位与非对称出球/宽度分工。
- 有球双肋部进攻中场：改为中前卫策应保持位置 + 肋部中场进攻自由前插，避免两人机械重复同一类前插。

### 新增待验证
- 无球双中卫 Trigger Press：较少；边后卫、双后腰、边前卫、中前卫、前腰 Trigger Press：更多。
- 无球压迫角色分层与高位遭遇线/极低防线组合；前场与中场主动干扰出球，中卫留在低位保护身后。
- 有球左侧内收型边后卫 + 右侧攻击型翼卫，配合左侧内锋和右侧组织型边锋，制造名义位置与实际行为错位。

### 证据不足
- 高位遭遇线是否完全独立于防线高度的底层触发；极低防线是否显著降低直塞/长传身后成功率；对手 AI 是否因此更多选择大脚、边路传中或中场推进。
- 个人压迫 PI 在各角色/职责下的完整原生权限与实际游戏内显示，以本轮 D1 预检和 D4 导入结果为准。
- 2.0 的实际 PPG、xG、xGA、重大机会、主客场差异和球员执行效果。

## 4. 唯一战术结构与协同设计

- 本轮唯一主线结构：IP 4-2-3-1（严格保留 DL/DCL/DCR/DR 四个后场位置槽）；OOP 4-2-3-1 的深防线/高遭遇线错位结构。
- IP 核心：左侧 DL 使用内收型边后卫（防守）占据内侧出球/保护区域；右侧 DR 使用攻击型翼卫拉开宽度并攻击后点；DCR 出球中卫短传，DCL 中后卫短传；MCR 中前卫保持位置，MCL 肋部中场自由前插；AMR 组织型边锋负责连接，AML 内锋攻击中路；AMC 进攻型组织核心自由移动并前插，ST 射手攻击后点。
- OOP 核心：DR/DL 压迫型边后卫；DCR/DCL 保护型中卫且减少主动逼抢；DMR/DML 双后腰承担身前屏障并更频繁上抢；MR/ML 回防边前卫覆盖边路；MC 与 AMC 主动参与压迫。
- 球队指令：较高节奏、较宽进攻宽度、极低防线、高位遭遇线、更多（非极多）团队逼抢、丢球后重新组织防守、积极铲抢、允许传中。
- 关键协同：前场第一压迫线尽量迫使对手后场仓促出球；双后腰负责压缩中场接球空间；双中卫不追随前场压迫而主动离位；低防线压缩身后空间。进攻阶段左侧内收、右侧拉宽，形成不对称宽度和出球点。
- 为什么不选 OOP 5-2-3 strikerless：V1.8 的历史结果较低，且没有足够证据证明其结构是收益来源；本轮先采用双后腰屏障保护深防线，并保留 OOP 四后场便于检验分层压迫机制。

## 5. PPG 导向的 D5 验证标准

- 联赛样本要求：优先完整 38 场联赛；不足 38 场时标明样本数，不与完整赛季等同。
- PPG 目标：≥2.85；同时记录积分、胜/平/负。
- 进攻指标：我方 xG/NPxG、绝佳机会、射门/射正、禁区内射门、实际进球与转化差额。
- 防守指标：对手 xG/xGA、绝佳机会、射门/射正、禁区内射门、身后球导致的机会（如报告可用）、实际失球。
- 主客场分项：分别计算 PPG、胜平负、xG/xGA 和重大机会。
- 平局/失利复盘：逐场检查对手如何越过第一线压迫、是否在中场获得转身空间、是否通过直塞/长传/边路传中创造高质量机会。
- 失败条件：若对手 xGA、禁区内高质量射门或重大机会明显恶化，说明深防线未能抵消中场过渡区风险；若我方 xG/重大机会下降，说明宽度/节奏/角色错位没有改善进攻；若高位压迫没有提高前场夺回或造成仓促出球，则需重新评估压迫结构。
- 不得用犯规、黄牌或红牌评价战术效果。

### 7.2 本轮至少一条具体错位机制链
- 错位类型：球队高位遭遇线 ↔ 极低防线 + 中卫较少主动逼抢、前场/中场主动触发；同时 IP 左后卫内收与右后卫攻击型前插形成不对称位置行为错位。
- 错位配置：OOP 团队 LINE_OF_ENGAGEMENT=HIGH_PRESS、DEFENSIVE_LINE=MUCH_LOWER、TRIGGER_PRESS=MORE_OFTEN；DCL/DCR 的个人 Trigger Press=LESS_OFTEN；DMR/DML、MR/ML、MC、AMC 与两名边后卫的 Trigger Press=MORE_OFTEN。
- 角色/指令默认行为与显式行为可能在哪里冲突：球队遭遇线要求前场尽早干扰，但中卫个人指令减少主动上抢；有球左后卫名义仍在 DL 槽，却以内收角色参与内侧站位；右后卫仍在 DR 槽，却以前插翼卫行为提供宽度。
- FM27引擎预期执行行为：待验证假设——高位遭遇线可能影响前场压迫起始区域，极低防线可能独立影响后防纵深；个人触发频率进一步分配各位置的主动上抢倾向。不得预设这些模块完全独立。
- 对手AI可能如何盯防、压迫、补位或重组：待验证假设——对手可能因前场压迫而加快出球/长传，也可能利用中场与深防线之间的空间；若对手前压盯防左侧内收球员，右侧宽度和肋部可能出现可用空间。
- 预期创造的空间、人数、跑动、接球或防守分配优势：前场压迫者负责干扰后场出球，双后腰压缩中场接球点，中卫保留纵深保护；进攻时左侧内收形成额外内线出球点，右侧翼卫与边锋形成外侧宽度和后点供给。
- 对PPG、胜率/平局率的收益路径：如果迫使对手仓促出球并减少中卫离位，可减少对手高质量机会；较宽进攻与较高节奏增加我方进攻回合和边路机会，预期降低被动平局/失利并提高 PPG。
- 可能副作用、失败条件：中场过渡区可能被对手利用；深防线可能让对手长期控球并增加传中；双后腰被拉开时中卫前方可能暴露；攻击型翼卫身后可能被反击攻击。
- D5量化验证指标与判定标准：比较对手 xG/xGA、绝佳机会、禁区内射门、前场夺回（若报告可用）、我方 xG/NPxG、绝佳机会、主客场 PPG 与 38 场积分；若对手重大机会或 xGA 上升、我方机会质量不升且 PPG 无改善，则该错位组合不准入。
