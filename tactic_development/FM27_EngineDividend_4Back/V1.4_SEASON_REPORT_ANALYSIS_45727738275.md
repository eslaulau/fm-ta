### 1. 继承保留
- IP 四后场 DL/DCL/DCR/DR：项目硬约束，必须保留。

- 其余 IP/OOP 角色、职责与 PI：在 V1.5 暂作结构性继承，单项效能未准入。
- 比赛节奏较高、进攻宽度较宽、团队逼抢较多等现有 TI：不因成绩好坏直接判定单项有效；下轮只针对防守风险调整必要项。

### 2. 替换淘汰
- 心态 `ment=4`（中性/平衡档）→ V1.5 `ment=3`（谨慎档）：这是针对高进球同时高失球、尤其客场失利增多的风险控制实验，不是宣称原心态普遍无效。
- 防线高度 `DEFAULT` → `LOWER`（较低）：针对对手绝佳机会与 xGA 上升，测试更深的防线能否保护身后空间。旧值只从本轮配方替换，不宣称在所有结构无效。

### 3. 新增待验证
- V1.5 心态 3 + 较低防线高度的协同组合；高位防守介入线与团队较多逼抢保持，形成“较低防线 + 高位压迫”的实验结构。
- 目标：降低客场 xGA、对手绝佳机会和失球，同时尽量保住 V1.4 的高 xG、绝佳机会和进球供给。
- 风险：谨慎心态可能压低进攻侵略性；较低防线可能让对手更容易进入中场/外围控球。必须同时监控进攻端损失。

### 4. 证据不足
- 无逐场战术配置、无完整 22 槽角色/职责/PI 事件映射；不能将 AML 变化直接归因为防守退步，也不能归因到特定 OOP 位置。
- 球员身份覆盖 93.53%；63 次出场未识别；3 球未归属。
- 目标 build 未被 fmsave 上游登记，局部数据读取采用借用 schema-6 布局。
- 没有同一存档、同一阵容、同 seed 的 V1.3/V1.4 受控实验。
