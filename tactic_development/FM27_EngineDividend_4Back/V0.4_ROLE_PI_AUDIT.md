## 1. 完整 IP/OOP 角色矩阵

| 槽位 | IP 角色/职责 | OOP 角色/职责 | 转换 | 位置与结构判断 |
|---|---|---|---|---|
| GK | BallPlayingGoalkeeper / S | Goalkeeper / S | 不变 | 出球门将支持短传发起；无球基础守门 |
| DL | **FullBack / S**（原 InsideFullBack / D） | PressingFullBack / S | 不变 | 左侧改为提供外线宽度，弥补 IF 内切与 HalfBack 回撤后的边路空缺 |
| DCL | BallPlayingCentreBack / D | CoveringCentreBack / D | 不变 | 左中卫负责推进出球，无球保护纵深 |
| DCR | **CentreBack / D**（原 OverlappingCentreBack / S） | CoveringCentreBack / D | 不变 | 右中卫留守，减少与右翼卫/边路前锋同时前插导致的空档 |
| DR | WingBack / S | PressingFullBack / S | 不变 | 右侧推进与底线传中；内收倾向给 AMR 留出外线空间 |
| DML | HalfBack / D | DroppingDefensiveMidfielder / D | 不变 | 有球回撤保护后场；无球主动触发压迫 |
| DMR | DeepLyingPlaymaker / S | PressingDefensiveMidfielder / S | 不变 | 有球短传控制点，无球参与前压 |
| AML | InsideForward / A | PressingCentralMidfielder / A | AML→MCL | 内切攻击；无球回收中场压迫 |
| AMC | SecondStriker / A | PressingCentralMidfielder / A | AMC→MC | 攻击锋线与肋部；无球回撤压迫 |
| AMR | WideForward / A | PressingCentralMidfielder / A | AMR→MCR | 右侧纵深/宽度与底线威胁；无球回撤压迫 |
| ST | FalseNine / S | TrackingAttackingMidfielder / D | ST→AMC | 回撤串联；无球跟踪对方前腰 |

**结构结论：** IP 仍为 4-2-3-1，OOP 仍为四后卫。V0.3 左侧 InsideFullBack 收窄、AML 内切、DML HalfBack 回撤叠加，缺少稳定宽度；右侧 OverlappingCentreBack、WingBack、WideForward 同时前进，出现右侧堆叠。V0.4 只针对这两处做非对称修正。

## 5. 变更与保留决策

| 项目 | V0.3 旧值 | 重做 V0.4 新值 | 预期/风险 |
|---|---|---|---|
| TI PASS_RECEPTION | PASS_INTO_SPACE | PASS_TO_FEET | 降低身后接球越位风险；直塞威胁可能下降 |

| IP DL | InsideFullBack/D + SIT_NARROWER | FullBack/S；仅 SHOOT_LESS_OFTEN | 补左路宽度；边后卫身后空间增加 |
| IP DCR | OverlappingCentreBack/S + SHOOT_LESS_OFTEN + SHORTER | CentreBack/D + SHOOT_LESS_OFTEN | 右中卫留守，减少右路堆叠；右侧套上减少 |
| IP AMC | DRIBBLE_MORE + ROAM_FROM_POSITION | 仅 ROAM_FROM_POSITION | 降低中路重复盘带，保留游弋 |
