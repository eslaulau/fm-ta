## V1.2 报告数据诊断

V1.2 2026/27 英超 38 场：26胜8平4负、72:29、86分；xG70.31、xGA39.97；我方绝佳机会76、对手33。V1.1 为 19胜10平9负、84:48、67分；xG81.73、xGA52.53；我方绝佳机会75、对手43。

V1.2 最主要收益在客场：12胜6平1负、31:13、xGA20.07、对手绝佳机会15；V1.1 客场 9胜4平6负、41:32、xGA33.22、对手绝佳机会31。V1.2 主场 xGA 19.90，接近 V1.1 的19.31；主场对手绝佳机会18，高于 V1.1 的12，因此不能把防守进步描述成主客场同等提升。

进攻端 V1.2 的场均 xG 1.85、射门13.29、传中尝试30.74、成功传中4.32、推进传球49.03，均低于 V1.1（xG2.15、射门14.42、传中33.16、成功传中5.34、推进传球51.58）；但绝佳机会76次略高于V1.1的75次，球队实际进球72也高于70.31 xG。诊断是整体/普通射门及边路供给量偏低，不是全季终结效率失常。平局组8场只进5球、xG9.80，是特定结果组的转化问题。

角色码仅部分记录可唯一解码；未识别球员身份仍有88次。球队/球员字段合计对账1,121/1,121；一场对富勒姆的球队比分多于球员进球明细1球，保留未归属。目标 build 未被 fmsave 0.14.3 upstream 登记，语义状态仍为 partial/unverified。分析细节见对应 V1.2 报告。

## 本轮设计目的

V1.2 的 OOP 防守架构产生明显客场防守收益，因此 V1.3 不拆它；本轮只针对进攻产量与边路供给做两个协调调整。两项均为待赛季验证的假设，不是已证实的因果机制。

## IP：保留四后卫与攻击角色骨架

| 位置 | 角色 / 职责 | V1.3 PI |
|---|---|---|
| GK | 出球门将（策应） | 短传 |
| DR | 翼卫（进攻） | 拉开宽度、后点传中 |
| DCR | 出球中卫（防守） | 短传 |
| DCL | 中后卫（防守） | 短传 |
| DL | 内收型边后卫（防守） | 短传 |
| MCR | 中前卫（策应） | 减少冒险传球、**更多前插** |
| MCL | 肋部中场（进攻） | 减少冒险传球、更多前插、自由跑位 |
| AMR / AML | 组织型边锋（策应） | 短传 |
| AMC | 前场组织核心（进攻） | 自由跑位、更多前插 |
| ST | 抢点前锋（进攻） | 更多射门、后点攻击 |

IP 后场四个位置仍严格是 DL、DCL、DCR、DR；未改动四后卫的位置、角色和职责。V1.2 所有其他 IP 角色和 PI 保留。

### 本轮 IP 实际变化

- MCR 中前卫（策应）：`FORWARD_RUNS=KEEP_POSITION` → `FORWARD_RUNS=MAKE_MORE_RUNS`。
- `PASSING_RISKS=TAKE_FEWER_RISKS` 保留，避免同时放开传球风险。
- 设计假设：V1.2 的 MCR 原先保持位置，限制了从中场区域跟进的纵深接应；新增更多前插可增加 MCL 肋部中场、AMC 前场组织核心和 ST 抢点前锋之外的第二线到位点。

## 球队指令变化

| TI | V1.2 | V1.3 |
|---|---|---|
| 比赛节奏 | 较高 | 较高 |
| 进攻宽度 | 标准 | **较宽（WIDER）** |
| 防线高度 | 标准 | 标准 |
| 团队逼抢频率 | 较多 | 较多 |

- 原生 TI bit 向量 V1.2：`[2,5,7,11,13,16,28,35,44,47,54,61,66,69,71,72,79,83]`。
- V1.3：`[2,5,7,11,13,16,28,35,44,47,51,54,61,66,69,71,72,79,83]`。
- 本轮新增 bit 51（进攻宽度较宽）；其他已声明 TI 保持原值。共享 12-byte TI 向量仍遵循父快照 opaque bits 保护规则。
- 设计假设：V1.2 的传中尝试/成功传中、推进传球、进攻三区传球均比 V1.1 低；较宽的进攻站位可能恢复横向拉伸和边路供给。风险是球员横向间距增大，可能削弱短传连接或增加丢球后的空当。

## 外部依据与边界

- metaFM 的 27.1.1 榜单头部仍以多种 IP 三后场或其他结构为主，并经常配合 OOP 5-2-3；榜单使用统一对手计划和球员条件，其结果与本队存档赛季不可直接换算。项目 IP 四后卫约束保持不变。[metaFM 27.1.1](https://metafm.net/leaderboard)。
- 27.1.1 官方小型热修复公开内容没有列出新的进攻角色机制变更；本轮以本队赛季数据作为迭代主要依据。[SI 27.1.1](https://community.sports-interactive.com/forums/topic/613511-preview-of-fm27-version-2711/)。
- 比较 V1.1/V1.2 赛季只能作为描述性证据；两次模拟不是相同随机种子/受控实验。V1.3 两项调整没有单项效果归因。
