## 来源完整性规则

- 用户确认的战术版本映射必须记录在本表。
- Run ID、原始 URL、游戏 build、存档 SHA、导出时间应从原始报告读取后登记；缺失项标注“未定位/待补录”，不得推断。
- 每个赛季分析文件必须注明其原始 Run ID，并链接回本登记表。
- 原始数据与分析结论分层保存：Exporter 原始 JSON/CSV 是源数据；本项目 Markdown 是分析层；recipe/build report 是战术版本层。
