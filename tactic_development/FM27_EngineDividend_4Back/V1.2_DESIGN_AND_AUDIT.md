## 战术设计逻辑

### 唯一硬约束

IP 后场仍是 DL、DCL、DCR、DR。四名后卫的角色、职责、PI 并不锁定；OOP 结构也不是项目硬约束。本轮保留 IP 主体只是因为本队数据尚不支持先拆掉创造和进攻链。

### IP：保留 V1.1

| 位置 | 角色 / 职责 | 个人指令 |
|---|---|---|
| GK | 出球门将（策应） | 短传 |
| DR | 翼卫（进攻） | 拉开宽度、后点传中 |
| DCR | 出球中卫（防守） | 短传 |
| DCL | 中后卫（防守） | 短传 |
| DL | 内收型边后卫（防守） | 短传 |
| MCR | 中前卫（策应） | 减少冒险传球、保持位置 |
| MCL | 肋部中场（进攻） | 减少冒险传球、更多前插、自由跑位 |
| AMR / AML | 组织型边锋（策应） | 短传 |
| AMC | 前场组织核心（进攻） | 自由跑位、更多前插 |
| ST | 抢点前锋（进攻） | 更多射门、后点攻击 |

IP 四后场位置为 DL、DCL、DCR、DR；DCL 已使用合法的普通中后卫，不使用只适用于三中卫外侧的边中卫。

### OOP：紧凑四后卫 + 三层中央保护

| 槽位来源 | OOP 位置 | 角色 / 职责 | PI |
|---|---|---|---|
| DR | DR | 留守边后卫（防守） | 无额外 PI |
| DCR | DCR | 中后卫（防守） | 较少地逼抢 |
| DCL | DCL | 补位中卫（防守） | 较少地逼抢（角色固定开启，不重复序列化） |
| DL | DL | 逼抢边后卫（策应） | 角色固定更多逼抢；凶狠铲抢 |
| MCR | DMR | 边路补位后腰（防守） | 较少地逼抢；凶狠铲抢 |
| MCL | DML | 屏障后腰（防守） | 角色默认屏障行为，无额外 PI |
| AMR / AML | MR / ML | 回防边前卫（防守） | 更多地逼抢、凶狠铲抢 |
| AMC | MC | 屏障中场（防守） | 无额外 PI |
| ST | AMC | 拉开接应前腰（进攻） | 更多地逼抢，作为唯一前场接应点 |
| GK | GK | 清道夫门将（进攻） | 谨慎铲抢 |

设计为左右不对称：右侧 IP 是更积极的翼卫，OOP 由留守边后卫稳定右侧；左侧 IP 是内收边后卫，OOP 由逼抢边后卫和回防边前卫承担选择性前压。DCR/DCL 保持较少逼抢，避免两名中卫同时离开最后防线；DMR 以边路补位为主，DML 负责屏障；MC 再补一层中路保护。前场不恢复传统 ST，ST 槽转为 AMC 拉开接应前腰，保留一个高位纵深出口。

### 团队指令

与 V1.1 相同，避免在 OOP 结构变化之外同时扩大团队指令变量：
- 比赛节奏：较高。
- 进攻宽度：默认。
- 防线高度：默认。
- 团队逼抢频率：较多。

原生 TI bit 向量：[2,5,7,11,13,16,28,35,44,47,54,61,66,69,71,72,79,83]。它是单一共享向量，不是独立 IP/OOP 两套 TI。

## 预期收益与风险

预期：
1. 让双后腰、屏障 MC 和回防宽中场构成三层覆盖，减少对手直接进入禁区前沿的空间。
2. 右侧留守边后卫和边路补位后腰保护 IP 高位翼卫身后的空间；左侧仍保留一个主动出击点。
3. 通过中卫较少逼抢和屏障中场减少中路空当，同时让回防边前卫承担宽区压迫。
4. 让前场接应点继续提供反击纵深，不彻底牺牲转换威胁。

风险：
1. OOP 由五后卫变为四后卫，边路一对一压力可能增加。
2. 更多球员回撤和屏障职责可能降低前场反抢人数，导致对手更容易从后场发起组织。
3. 若 MC/DMR 站位过深，前场接应点可能孤立，反击连接速度下降。
4. 选择性 Tackle Harder 只是待验证机制，不用犯规、黄牌或红牌评价；应看抢断成功、球权恢复、对手推进和 xGA。
