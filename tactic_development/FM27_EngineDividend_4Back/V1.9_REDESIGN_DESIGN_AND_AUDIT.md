## D1｜唯一整体设计

### 阵型结构

- **IP：4-3-3 DM（4-1-2-3）**。唯一硬约束后场四槽严格为 DL、DCL、DCR、DR；中场为单DMC + MCL/MCR双中前卫；前场为AML、AMR双边锋 + ST。
- **OOP：4-1-4-1**。后场仍为DR、DCR、DCL、DL；单DMC屏障；MCR/MCL双中场；MR/ML回防边前卫；ST作为反击出口。
- 不固定4-2-3-1；本版IP无AMC，也不是V1.7或V1.8的阵型复制。

### 结构协同逻辑

- IP前场保持三人攻击线，避免把V1.8已经产生高xG/高绝佳机会的边路与中锋产出全部拆掉。
- 将原V1.8的AMC进攻槽改为DMC防守中场，形成单后腰 + 双中前卫；这是本版IP最重要的整体结构变化，目的是减少中路丢球后直接暴露中卫的情况。
- 右侧翼卫进攻与左侧内收边后卫形成非对称宽度/连接；IP纸面后场四槽仍严格为DL/DCL/DCR/DR。
- OOP不再使用V1.8的五后卫翼卫前顶结构；两名边后卫留守，双边前卫回收，DMC屏障，双中场一压一保，形成4-1-4-1紧凑中低/中高位防守框架。
- OOP前场只留一个中锋出口；其余边锋回收到MR/ML，不把三名前场球员同时留在高位导致中场保护人数不足。

### 团队指令与心态

- 心态：4（积极）。
- 保留：比赛节奏较高、进攻宽度较宽。
- 得球后：立刻反击；后场组织：通过传递破解逼抢；接球方式：传入空当。
- OOP：高位逼抢介入线、标准防线高度、团队逼抢较多、丢球后立即反抢、阻止传中、诱导至边路。
- 团队逼抢不设极多；采用较多团队触发并在个人角色层级分化。标准防线高度与高位介入线组合，避免把整条防线推至极高。
- 个人PI：OOP所有10名外场球员配置“更凶狠地铲球”作为用户研究中的广泛候选；中卫/屏障角色维持较少主动逼抢，边前卫与主要压迫中场更多主动逼抢。效果只用抢断/拦截/球权恢复、对手推进、对手射门质量和xGA评估；犯规、黄牌、红牌不进入评价。

## 父子版本四类决策

### 1. 继承保留
- IP四后场位置槽DL/DCL/DCR/DR；不固定其他IP阵型。
- 保留V1.8中已有正向产量观察的右侧宽度、左侧内锋、抢点前锋、MCL肋部纵深和MCR中场连接机制，但将其重新嵌入4-3-3 DM。
- 心态4、较高节奏、较宽进攻宽度作为有意选择保留；不是规则锁定。
- 个人指令仅在当前角色权限允许时保留；不因父版本存在就默认有效。

### 2. 替换淘汰
- V1.8 OOP 5-2-3：整组从本轮主线撤下；这不是证明所有5-2-3都无效。
- V1.8 IP的AMC前场组织核心位置：改为DMC防守中场，重建单后腰 + 双中前卫结构。
- OOP WBL/WBR逼抢翼卫、三中卫、前场AML/AMR高位边锋：改为四后卫 + 单屏障 + 双回防边前卫。
- 不再将V1.7完整4-2-1-2-1作为默认回退模板。

### 3. 新增待验证
- IP 4-3-3 DM与OOP 4-1-4-1之间的双形态转换。
- 单DMC + 双中前卫的IP保护与推进协同。
- OOP双边前卫回收、双中场一压一保、两名留守边后卫的机会控制效果。
- 高位介入线 + 标准防线 + 较多团队逼抢 + 丢球后反抢的组合。
- OOP全队外场“更凶狠地铲球”与分层逼抢的协同效果。

### 4. 证据不足
- metaFM的4-3-3 DM领先样本使用OOP 5-2-3；不能把它的1.882 PPG直接预测到本版4-1-4-1 OOP。
- metaFM与FM-Arena协议不同；不能合并样本。
- 本队V1.7/V1.8不是同seed受控A/B；Exporter缺逐场战术槽位映射，不能将赛季球员表现归因于角色/PI。
- V1.8 exporter build解析状态partial/unverified；V1.9报告必须继续标注同类风险。
