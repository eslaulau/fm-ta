# FM27 引擎红利四后卫｜历史指令效能与行为错位审计（2026-11-26）

## 0. 本轮审计边界与结论

本文件是对 V0.5–V1.8 完整赛季报告、V0.6–V1.8 机器配方及 FM27 原生 catalog 的第一轮字段级交叉审计。不是新战术设计，也不把任何候选称为已验证 META。

**原生可配置空间的实际规模：**
- 球队指令：29 组、103 个可选项；
- 球员个人指令：17 组、54 个可选项；
- 原生角色：79 个；
- 职责枚举：7 个原生 duty 值；
- 另有位置、IP/OOP 阶段、阵型转换和心态维度。
因此，不是“几十条指令”而是一个有大量交互项的配置空间。不能靠几份版本摘要或一两次微调覆盖。

**当前最重要的审计结论：**
1. 历史战术没有均匀探索 157 个 TI/PI 选项。大量选项从 V0.9 到 V1.9 被固定继承；“出现 11 次”只说明沿用，不能说明有效。
2. 最强的字段级证据来自少数近邻版本：V0.9→V1.0 的两项 TI 联合变化、V1.2→V1.3 的宽度+MCR前插联合变化、V1.3→V1.4 的 AML角色/PI变化、V1.4→V1.5 的心态+防线变化、V1.6→V1.7 的双后腰压迫层级变化、V1.7→V1.8 的OOP结构变化。
3. 这些仍是不同存档赛季的描述性比较，不是同 seed A/B。可用于发现强信号、提出行为机制假设、淘汰明显失败的配置簇；不能把每一项单独判成因果真理。
4. **“指令文字”与“实际行为”的错位必须作为独立研究对象。** 例如：更高团队逼抢不等于所有球员都应更频繁前顶；边后卫进攻阶段拉宽与无球阶段留守/压迫职责可以反向分工；无锋前场结构可以同时增加反击出口和扩大防守空间风险。必须沿着角色默认行为、PI覆盖、TI全队作用、位置转换与邻位补位一起审查。

## 3. 近邻版本差异：目前最有价值的字段级证据

### 3.1 V0.6 → V0.7：负向协同簇

变更包括：
- 团队比赛节奏：极高→较高；
- 进攻宽度：极窄→较窄；
- 团队逼抢：极多→较多；
- MCR：肋部中场（进攻）→中前卫（策应），前插改为保持位置；
- AMC：肋部中场（进攻）→前场组织核心（策应）。

结果：积分68→53（-15）；进球83→70；失球49→58；场均xG约2.108→1.810；场均对手xG约1.182→1.485；射门、射正、绝佳机会也下降。共同赛程样本显示传球量/前场三区传球基本没有增加，攻击威胁却下降。

**判断：** “增加稳定接应点就会改善推进”的设计假设在该版本组合下失败；把多个攻击职责回撤、同时降低节奏和团队逼抢，形成了进攻与防守双向退化的负向配置簇。不能单独断言是某一条TI或AMC/MCR造成，但此类组合应列为当前不利，不能无条件复用。

### 3.2 V0.7 → V0.8：恢复纵深与高强度的组合回弹

变更：
- 节奏：较高→极高；
- 宽度：较窄→极窄；
- 团队逼抢：较多→极多；
- AMC前场组织核心：策应→进攻，并启用更多前插；
- MCR稳定接应保留。

结果：53→66分；场均xG约1.810→2.160；场均xGA约1.485→1.158；共同赛程xG/xGA均明显改善。

**判断：** 恢复纵深攻击职责与提高比赛节奏/团队压迫的组合有正向观察。尤其说明“更积极前插”不能与“稳定接应”简单对立：把一个中场留作连接、另一个前腰重新前插，可能比所有中路位置同样回撤更有效。但由于TI和角色同时变化，暂列协同级正向候选，不给单项准入。

### 3.3 V0.9 → V1.0：团队宽度与防线高度的联合错位修正

唯一TI变化：
- 进攻宽度：较窄→标准；
- 防线高度：较低→标准。
比赛节奏较高、团队逼抢较多保持不变。配方中仍存在DCL宽中卫用于四后卫的适用性问题，因此其角色不能作为有效四后卫机制证据。

结果：80→87分；86:48→107:35；xG +11.57；xGA -3.17；我方绝佳机会68→92；对手绝佳机会36→28。客场xG/xGA与推进均改善。

**判断：** 这是当前最强的TI联合变化正向观察。它反驳“较窄进攻宽度+较低防线天然更适合四后卫反击”的固定教条。较宽/标准的横向展开可能让进攻出口和前场进入更充分；标准防线可能缩短高位压迫线与后防之间的纵向距离。两项同时改变，不能拆分因果；但该组合应作为高优先级候选重新测试。

### 3.4 V1.0 → V1.1 → V1.2：OOP结构实现方式比“阵型名称”更重要

V1.0→V1.1：IP主体保留，但DCL由四后卫不适配的宽中卫修正为普通中后卫；OOP从紧凑四后卫/双后腰/回防宽中场改成五后卫、双后腰、无锋前场三人组，同时角色、位置转换和压迫分工大幅改变。结果87→67分，xGA 40.07→52.53，对手绝佳机会28→43，尤其客场xGA从22.52升至33.22。

V1.1→V1.2：OOP重新设计为四后场底线、左右不对称边后卫、双后腰、双回防边前卫、屏障中场和前场接应点。结果67→86分，xGA 52.53→39.97，对手绝佳机会43→33；但xG 81.73→70.31、进球84→72。

**判断：** OOP 5-2-3的第一种角色/压迫实现失败，不等于整个5-2-3家族无效。真正影响执行的包括：边翼卫是否同时前顶、宽中卫是否外扩、中场是否回撤成第三中卫、前场三人是否保留高位、双后腰是否有屏障与边路覆盖分工。V1.2证明更完整的后场保护可降低xGA，但存在进攻产量代价。必须研究空间和职责，而不是只比较“4-2-1-2-1/5-2-3”标签。

### 3.5 V1.2 → V1.3：进攻宽度与中场纵深的协同候选

变更：
- TI进攻宽度：标准→较宽；
- IP MCR中前卫策应：保持位置→更多前插；
- 其余结构和主要配置保持。

结果：86→88分；进球72→83；xG +10.23；xGA -5.70；推进传球增加；但我方绝佳机会76→65。不是每个机会指标都改善。

**判断：** “较宽进攻宽度 + 中场后插上”是有价值的协同候选：可能同时拉开横向通道并补充第二线进入禁区。但大机会数下降提示新增威胁可能更多来自普通射门/不同xG分布。需查射门位置与接球点，不能把更多传中或更多射门等同于更好机会。

### 3.6 V1.3 → V1.4：AML内锋组合呈现明确进攻增益与防守代价

唯一IP配置簇变化：
- AML组织型边锋（策应）→内锋（进攻）；
- 增加带球内切、自由跑位；
- OOP和共享TI保持。

结果：进球83→101（+18）；xG80.54→92.62（+12.08）；我方绝佳机会65→100（+35）；但xGA34.27→43.46（+9.19）、对手绝佳机会27→39（+12）、失球30→53（+23）、积分88→83（-5）。

**判断：** 这是一个重要的“阶段行为错位”候选：有球阶段AML从边线连接/组织点转成内侧终结与纵深攻击点，明显提高进攻产量；但该球员无球仍回到ML回防边前卫，且全队防守结构没有相应改变。进攻阶段增加内侧攻击人数，可能让丢球后左侧回防与中场屏障的覆盖关系更脆弱。此机制与结果相容，但不是已证明因果。AML内锋+内切+自由跑位应作为进攻增益候选；不能无配套OOP覆盖地直接判定为全局最优。

### 3.7 V1.4 → V1.5：谨慎心态+较低防线不是理想修复

变更仅：
- 心态：4→3；
- 防线：标准→较低。

结果：83→78分；xG92.62→77.29（-15.33）；我方绝佳机会100→87；xGA43.46→40.51（-2.95）；失球53→48（-5）；进球101→95（-6）。

**判断：** 该组合以较大进攻产量损失换来有限xGA改善，未修复客场防守（客场xGA从23.28升至24.68，对手绝佳机会22→25）。因此“低防线+谨慎心态”当前组合下不利于积分目标；不能作为默认防守修复法。此结论针对组合，不推广到所有高压迫或低防线搭配。

### 3.8 V1.5 → V1.6：积极后腰压迫与成绩转化之间存在冲突

变更：
- 心态3→4；
- 防线较低→标准；
- OOP DMR边路覆盖后腰：个人逼抢较少→较多；
- OOP DML屏障后腰→逼抢后腰。

结果：78→89分（历史最高）；进球95→87，xG77.29→75.54；失球48→37；但xGA40.51→46.33（恶化5.82），对手绝佳机会40保持40。

**判断：** 89分不能证明双后腰积极逼抢是防守最优。实际失球减少11，但机会质量反而恶化，且V1.6进球比xG高11.46，存在明显正向结果转化。该配置可能提升夺回球权/进攻回合或比赛结果，但不能从现有指标断言。双后腰同时主动前顶应列为“高积分但机会控制风险”的条件性方案，不应自动沿用。

### 3.9 V1.6 → V1.7：后腰分层保护的防守收益信号

变更集中在OOP双后腰：
- DML逼抢后腰→屏障后腰；
- DMR个人逼抢较多→较少；
- 其他主要IP角色/PI与共享TI/心态保持。

结果：89→82分；xGA46.33→44.13（改善2.20）；对手绝佳机会40→30（改善10）；我方绝佳机会63→72（增加9）；进球87→79；失球37→36。实际积分下降主要伴随进球与转化下降，不能把它说成防守设计失败。

**判断：** 这是双后腰错位分工的正向机会控制线索：一人屏障、不主动离位，另一人负责边路覆盖且降低主动压迫；两名中卫同样较少主动前顶。它降低对手大机会，但也可能牺牲主动夺回与反击起点。该组合值得保留为防守结构候选，并研究能否通过其他前场压迫点补回进攻转换，而不是让两个后腰同时压迫。

### 3.10 V1.7 → V1.8：无锋5-2-3产生明显的双向放大

**IP 11槽的角色/职责/PI与共享TI保持不变；主要变化是OOP 4-2-1-2-1→无锋5-2-3，含两翼卫、三中卫、双后腰和前场三人。**

结果：积分82→72（-10）；进球79→98（+19）；xG74.29→约88.87（+14.58）；我方绝佳机会72→96（+24）；同时失球36→55（+19）；xGA44.13→约59.67（+15.54）；对手绝佳机会30→50（+20）。

**判断：** 这是目前最清楚的“无球结构反向影响有球产出”的现象：同一IP进攻配方在不同OOP结构下，进攻产量大幅变化。OOP 5-2-3增加前场出口/无锋接应后，可能在夺回球权后制造更多快速纵深攻击；但翼卫/边中卫/中场回撤关系也同时让防守机会量暴增。它不是简单的“5-2-3好”或“5-2-3坏”，而是一个高攻击、高风险的引擎行为组合。未来应研究如何保留前场三出口/纵深反击收益，同时通过角色默认行为、边翼卫职责、后腰覆盖与中卫保护减少防守暴露。

## 5. 明确识别出的行为错位候选（不是结论）

### A. 团队压迫与个体压迫错位
团队“较多逼抢”并不要求中卫也积极前顶。历史配置中反复出现：边后卫/回防边前卫/前场接应点更积极，中卫较少触发逼抢，边路覆盖后腰较少逼抢、屏障后腰不叠加PI。该配置意图是让前场/边路压迫触发，而中卫与后腰维持保护。需要通过对手推进、抢断/恢复、对手xG和绝佳机会检验，不使用犯规/黄牌/红牌。

### B. IP进攻职责与OOP回防职责错位
AML有球阶段内锋进攻、内切和自由跑位，无球阶段同一槽位回到ML回防边前卫。该错位可能让球员在进攻时离开边线、攻击肋部，而防守时仍负责宽区回收。若邻位没有覆盖其内切后留下的边路空间，进攻收益可能以反击暴露为代价。V1.4/V1.8的xG与xGA同时上升，与该风险相容。

### C. 前场无锋出口与后场保护错位
V1.8 OOP三名前场球员可能提高夺回球后的第一/第二接应点，解释同一IP配方下xG显著增加；但翼卫上提/中卫外扩/中场回撤等组合也可能放大边路与肋部防守空间。应寻找“保留前场三出口，但降低翼卫同时前顶或调整后腰覆盖职责”的组合，而不是简单放弃无锋。

### D. 进攻宽度与位置跑动错位
V1.3宽度较宽与MCR更多前插共同变化，可能通过外侧拉开与中路第二线攻击互补；若两者同时窄缩或多个球员都内收，则可能产生同一区域拥挤。需要用接球位置、禁区触球、射门位置和前场通道数据确认，不能只看总射门。

## 6. 目前不能给出“强/弱”定论的原因

- 多数赛季并非同一存档、同一seed、同阵容/体能/球员状态的重放；样本比较是描述性。
- Exporter没有每场战术槽位映射；用户手工确认版本归属，不能将球员数据猜到角色/PI。
- 某些build下role_code只部分解码，且无球phase覆盖不完整。
- 团队统计没有完整压迫尝试/成功、位置级跑动/站位、传球线路封锁、接球点、射门坐标/事件链等字段。
- 157个TI/PI选项与79个角色的完整交互组合远大于当前版本数；历史只测试了少数配置簇。

因此本审计允许给出“高优先级候选”“当前组合下不利”“证据不足”，但不伪造单项因果结论。

## 7. 后续研究执行顺序

1. **原生语义与默认行为矩阵：** 对79个角色逐一提取默认行为、职责差异、位置适用范围、固定PI、可叠加PI、相互排斥项；对157个TI/PI选项记录阶段、全队/个人作用域、互斥位与覆盖逻辑。
2. **历史字段差异矩阵：** 以V0.5–V1.8为全样本，逐项编码每个版本11个IP/OOP槽、PI、TI、心态和转换位置；统计每个字段在哪些版本/结果组出现，而不把频次等同收益。
3. **结果/机制匹配：** 将每个差异簇与积分、xG/xGA、绝佳机会、主客场、推进、射门质量和比赛非胜场对应；给出正/负/混合/未知四类证据等级。
4. **外部引擎行为交叉：** 只引用能核对版本/build、测试协议、完整IP/OOP、角色/职责/PI/TI的战术；不能把榜单阵型标签当作完整机制。
5. **整体机制设计：** 在IP四后场硬约束下，允许重构其余七个IP槽和全部OOP结构；设计一套完整战术，明确每个错位机制如何运行、相邻位置谁补位、失败时损失什么。
6. **D4/D5验证：** D4核对游戏内导入和真实显示；D5使用用户明确确认的版本归属，完成至少38场。达到109分才算最终目标成功。

## 8. 结论

现在已经可以明确指出：本项目过去的主要错误不是“没有更多选项”，而是没有把原生目录的广阔选项空间与历史完整配置、赛季表现、角色默认行为和IP/OOP转换进行系统交叉。最有价值的历史线索不是单条“最佳指令”，而是以下几类协同：
- 标准/较宽进攻宽度与标准防线的联合配置；
- AML内锋进攻/内切/自由跑位的高进攻产量与无球保护风险；
- 团队压迫较多、前场/边路个人压迫较多、中卫和屏障后腰较少主动前顶的分层压迫；
- 屏障后腰+边路覆盖后腰的分工；
- OOP无锋前场三出口对IP进攻产量的放大，以及其防守空间成本。

这些是下一轮真正值得深入验证的机制候选。**本文件不生成新FMF，不把2.4或任何历史版本称为已验证升级。**
