# 历史 GEN1 配方与原生 FMF 离线生成验收清单

**用途：** 检查历史 GEN1 配方的结构兼容性，以及由原生生成器产出的 FMF 和同次回读报告。GEN1 是旧中间配方；新战术正式输入是结构化 JSON。正常生成任务完成第 C 节 D3 并交付真实 FMF 文件及报告，即为本项目完整交付。

## A. 设计与原生权限

- [ ] IP/OOP 阵型与 11 个槽位的阶段位置明确。
- [ ] 角色名称与 FM27 原生菜单显示名完全一致（含空格、连字符和大小写）。
- [ ] 按阶段、位置上下文、角色 ID、duty 检查所有角色。
- [ ] 按阶段、位置、角色与 duty 检查每一条 PI。
- [ ] 位置别名只用于权限查询；GEN1 和最终 native selector 的写入规则已单独核对。
- [ ] 未知权限标为未知，不以推测代替验证。

## B. GEN1 结构与生成器可接受性

- [ ] 前缀为 FM27GEN1:，Base64 解码为合法 JSON。
- [ ] 根字段 v/name/ment/base/ti/p 完整。
- [ ] base.g、base.ip、base.oop 与战术设计和选用模板一致。
- [ ] p 恰好 11 个槽位，每槽有 in/out。
- [ ] 每阶段的 pos、role、pi 字段完整；PI 为准确二元组且无重复键。
- [ ] 当前 Python 白名单、catalog role/position/phase eligibility 和 duty 映射均可接受本配方。
- [ ] 已确认 GEN1 v1 不含独立 duty 字段，职责由生成器按角色映射。
- [ ] TI 不得按历史规范臆造支持项：本版生成器仅支持字段契约所列映射；TI 是单一共享 12 字节向量。
- [ ] 对 GEN1 未声明的 TI key，已核对模板继承值；需要重置且当前映射支持的项目使用显式 DEFAULT。

## C. 离线原生 FMF 生成与 D3 回读（必做）

- [ ] 使用本次 GEN1 TXT 实际运行 FM27GEN1_Offline_FMF_Generator.py，并传入目标原生 FMF 模板和 catalog。
- [ ] 生成命令成功返回（exit code 0），没有异常或未处理错误。
- [ ] 本次目标 .fmf 文件实际存在且非空，不是复用旧样本或改名的历史输出。
- [ ] 与该 FMF 同次生成的 .report.json 文件存在且可解析。
- [ ] 报告中的 FMF 容器成员、解密/解压长度和 TAC 结构检查通过。
- [ ] 11 组 IP/OOP 槽位均已回读。
- [ ] 22 个阶段的位置、角色和 PI mask 与本次 GEN1 输入一致（对 OOP STC→ST 规范化作正确比对）。
- [ ] duty bit 检查通过，并明确其硬编码来源/推断限制。
- [ ] TI 向量回读一致；未在 GEN1 中指定的项目已按模板继承规则核对。
- [ ] 报告状态明确为离线二进制回读通过，并逐项列明本次实际完成的检查。
- [ ] 用户实际收到本次 .fmf 和对应 .report.json；GEN1 可作为辅助源文件一并提供。

**任一项未通过：不得标记 D3，不得称已完成原生 FMF 生成。**
